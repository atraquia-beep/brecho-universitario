# Take It

Protótipo do Take It, o brechó do campus de Limeira: um brechó entre alunos em que as peças novas entram todas juntas, com hora marcada (o drop). Feito para o vídeo do MVP de MG900 – Empreendedorismo.

Site estático (HTML, CSS e JavaScript puros). Para abrir, dois cliques em `index.html` ou o link publicado.

Roteiro de gravação, o que é simulado e como trocar as fotos: [LEIA-ME.md](LEIA-ME.md).
