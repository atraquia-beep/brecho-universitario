# Brechó Universitário

Protótipo do "drop do campus": um brechó entre alunos em que as peças entram todas juntas, com hora marcada. Feito para o vídeo do MVP de MG900 – Empreendedorismo.

Abrir no celular ou no computador: https://atraquia-beep.github.io/brecho-universitario/

Roteiro de gravação, o que é simulado e como trocar as fotos: [LEIA-ME.md](LEIA-ME.md).
